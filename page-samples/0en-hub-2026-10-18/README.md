# 0EN Hub トップページサンプル

作成日: 2026-10-18

Product Designプラグインで制作した3案の画像モックと、ブラウザで比較するための静的HTMLです。既存サイトは変更していません。

## 開き方

このディレクトリの `index.html` をブラウザで開いてください。ビルド・インストール不要です。GitHubのファイル表示ではHTMLはページとして実行されません。リポジトリを取得してローカルで開くか、既存の静的ホスティング設定で配信される場合に利用してください。このコミットは公開設定を変更しません。

## 表示順とファイル

| 案 | 方向 | ファイル |
|---|---|---|
| 1 | 検索ファースト | 01-search-first.html |
| 2 | コンパクトな索引 | 02-compact-index.html |
| 3 | やさしい案内所 | 03-friendly-guide.html |

番号はチャットに生成画像が表示された順です。計画時の列挙順とは異なります。

## 範囲・制約

- 画像モックの比較用サンプルです。検索、登録、カテゴリ絞り込み、WORK詳細ページ、評価は未実装です。
- 各画像にPCとスマートフォンの想定表示が含まれます。比較ページ自体も画面幅に合わせてレイアウトしますが、画像内UIのレスポンシブ動作を検証したものではありません。
- WORK名、説明、画像、ステータスはデモ表現です。実際の公開・募集・配布状況を示しません。
- 実データに基づく評価がないため、星評価は載せていません。
- 全カードは共通のWORK詳細ページへ進む設計を前提とし、外部サイトへの入口とWORK同士の接続は詳細側で扱います。
- 実装時は全案でスマートフォンの「WORKを紹介する」を常時見える位置に置きます。案2・3の画像ではメニューに隠れており、ユーザー要件に対する修正が必要です。
- 既存トップ、求人機能、認証、DB、公開設定は変更していません。
- PNG生成結果を表示用WebPへ形式変換しています。
- HTML構造・参照先の静的確認のみ。ブラウザでの視覚検証は未実施です。
