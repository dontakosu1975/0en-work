# 0EN WORK

0EN WORKは、**誰かの「WORK」と、誰かや何か、WebやSNSをつなぐHub**を目指して開発しているプロジェクトです。

ここでいう「WORK」は、仕事だけを意味しません。アプリ開発、Web、ゲーム開発、編み物、裁縫、木工、金工、3Dプリンタ、音楽、求人広告・採用活動など、誰かが何かに取り組んでいることを広く含みます。

0ENでは、自分のWORKや、便利だったWORKを「紹介」し、作者・活動者のホームページ、GitHub、X、Threads、配布ページなどへたどれるようにします。また、WORK同士のリンクや相互リンクを大切にし、一つのWORKから別のWORKへつながっていくネットワークを目指します。

0EN自身がすべてを保管・配布したり、大規模SNSとして利用者を囲い込んだりするのではなく、**見つける・紹介する・つなぐための入口**になることを基本とします。

## 求人機能について

0EN WORKは、もともと「求人掲載 0円・応募 0円・採用 0円」を目指す求人サービスとして開発を始めました。

求人の考え方と既存機能は今後も継続します。ただし、求人広告・採用も0EN WORKに存在する一つの「WORK」として位置付けます。

現在開発している求人関連機能には、求人原稿の作成・管理、Airワーク等からの取り込み、無料掲載、公開URL、SNS・LINE・QR等への共有、企業指定の応募先への導線などがあります。

## 新しい上位構想

2026-10-18、0EN WORK全体の位置付けを求人だけに限定しない方向へ拡張しました。

詳細は [`docs/0EN_WORK構想_v0.2.md`](docs/0EN_WORK構想_v0.2.md) を参照してください。

主な考え方は次のとおりです。

- WORKを「仕事」に限定しない
- 「投稿」より「紹介」を中心にする
- 作者HP、GitHub、SNS、配布先等への外部リンクを重視する
- 相互リンクを主要機能として扱う
- WORK同士がジャンルを越えてつながれるようにする
- 作者・紹介者自身が能動的に参加できるようにする
- AIは調査、紹介候補、リンク候補、リンク切れ確認等の裏方として利用する
- 0ENが保証しない外部アプリ・サービスについては、その立場を明示する
- 求人機能は一つの大きなWORK／ジャンルとして継続する

既存の求人向け基本方針・公開ポリシー・利用規約案等は、求人サービスを前提として作成されたものです。新構想に合わせた改訂は今後行います。

## Cloudflareでの公開

公開先ドメインは `0en.work` です。`main` へのpushでCloudflare Workersの自動ビルドが開始される構成です。

| 項目 | 確認内容 |
|---|---|
| Gitリポジトリ | `dontakosu1975/0en-work` |
| 更新ブランチ | `main` |
| 自動ビルド | `Workers Builds: 0en-work` |
| 現在の公開ファイル | リポジトリ直下の `index.html` |

HTML自体のビルド処理はありません。Cloudflare側のBuild command、Deploy command、静的アセットのディレクトリ指定は管理画面で確認してください。このリポジトリには、現在Wrangler設定ファイルやpackage.jsonはありません。

## 更新とデプロイの確認

1. 変更したファイルを確認し、コミットして `main` へpushします。
2. Cloudflareの対象プロジェクトで、pushしたコミットに対応するデプロイが開始されたか確認します。
3. デプロイの成功とコミットIDを確認します。
4. 公開ページを確認します。

APIキー、トークン、ローカルの環境変数ファイルはコミットしないでください。
