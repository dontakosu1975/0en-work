# 0EN WORK 全画面統合PoC v0.3

作成日：2026-10-09。対象：`poc/0en-integrated-v0.3`。frontend-designを使用。

## 目的

新しい機能を増やす前に、既存のAirワーク取込、企業向け求人入力、企業ポータル、求職者向け画面を一つのブラウザ内でつなぎ、求人を作る企業と探す求職者の導線を確認する。

## 一周できる導線

`求職者トップ → 求人検索・詳細 → 求人を掲載する → 企業TOP → 求人管理 → 新規作成／Airワーク取込／Excel・CSV・TXT取込 → 6画面入力 → 途中保存／完成保存 → 求人管理 → プレビュー → 0EN掲載 → 求職者側の検索・詳細 → 企業指定応募先`

求職者トップから企業画面へは同じタブで移動する。企業画面では企業TOP、求人管理、採用ツール、ヘルプ、企業情報を共通ヘッダーで行き来できる。管理画面の原稿ごとに、掲載状態に関係なく「プレビュー」を表示する。

## プレビュー

`company/preview.html` が同じlocalStorageのJobを読み、最新Revisionを求職者側の表示形式へ投影する。未掲載・作成中の原稿も確認できるが、プレビュー内から応募は行わない。PC／スマホ幅をダイアログ上で切り替えられる。公開求人側は従来どおり、PublicationCycleが参照する完成Revisionだけを表示する。

## 保存と境界

v0.3は `0en-integrated-poc-v03` という独立localStorageキーを使う。v0.1／v0.2の保存データを上書きしない。正式な認証、D1、メール、法令チェック、実公開、応募者情報保存は未実装。掲載操作は既存PoCの模擬操作で、公開時点のRevisionを固定する。

## 検証

- Node：`node --check`（root/app、shared、company/app、preview）と既存の `node test.cjs` を実行。
- ブラウザ：4178で求職者トップ→企業画面の同一タブ遷移、求人管理→プレビュー、PC／スマホ切替、企業TOP→Airワーク取込→入力iframe、求職者一覧の390px横はみ出しなしを確認。
- 1440pxの企業管理・プレビュー・Airワーク取込画面を目視。プレビューは未掲載の架空原稿が表示され、応募ボタンを出さない。

## 起動

`poc/0en-integrated-v0.3` で `node server.cjs` を実行し、http://127.0.0.1:4178/ を開く。`/`・`/jobs`・`/company/`・`/company/importer`・`/company/editor`を同じサーバーで提供する。

## 次の判断

次に確定すべきなのは、企業マスタを求人入力へ自動反映する範囲、プレビューと公開表示の共通コンポーネント化、そしてログイン導入後もlocalStorage接続をどこまでサーバー側へ移すか。ここでUIを確認してからDB設計へ進む。

## 企業URLと共有（2026-10-09追記）

プレビューは管理用の項目確認画面ではなく、求職者向け求人詳細に近い構成（見出し、概要、仕事内容、給与、勤務時間、休日、待遇、試用期間、応募案内）で表示する。企業側の確認バーを残しつつ、原稿の見え方を判断できることを優先した。企業情報の「会社のWebサイト」は保存済みプロフィールから安全なHTTP(S)リンクとして表示する。

企業情報画面には既存の「会社のWebサイト」入力があるため、新しい求人スキーマは追加していない。v0.3ではプロフィールを `0en-company-profile-v03` に保存し、プレビューと公開詳細からリンクできるようにした。ユーザー名・パスワードを含むURLやHTTP(S)以外のURLはリンク化しない。

掲載中の求人管理行・求職者一覧・公開詳細の共有導線から、次を選べる。

- 対応端末：Web Share APIの標準共有メニュー
- 非対応端末：X、Threads、Facebook、LINEの共有URL
- 共通：公開求人URLのコピー

SNS API、ログイン情報、企業アカウントへの自動投稿は使わない。企業が自分のアカウントで最終投稿する方針により、0EN側の認証・運用負担と誤投稿リスクを抑える。

## SNS流通の追加案

今回の共有導線を土台に、実装順は次の候補とする。

1. 本番ドメインの短い公開URLとOGP（SNSに会社名・職種・給与・画像を表示）
2. 求人URLから生成するQRコード（店頭・紙・説明会向け）
3. 企業サイトへ貼れる求人カード／埋め込みコード
4. 仕事内容・給与・QRを組み合わせたSNS投稿画像テンプレート

候補はすべて「0ENが集客を独占する」のではなく、企業が既に持つSNS・Web・紙媒体へ求人を流通させる補助として評価する。OGPと公開URLを先に確定し、QR・埋め込み・画像は共有導線の利用状況を見て追加する。

## サービス説明ページ（2026-10-09追記）

企業・求職者の双方が0ENの境界を理解できるよう、次の静的ページを統合PoCへ追加した。

- `/about`：求人原稿を作成・確認・公開・共有する流れ
- `/principles`：企業向け／求職者向けの「やること・やらないこと」
- `/guides`：求人担当者向けの書き方、AI補助の使い方
- `/privacy`、`/terms`：正式公開前の確認版であることを明記した文書ページ
- `/contact`：`info@0en.work`への問い合わせ導線

求職者向け求人詳細と企業ポータルのフッターからリンクし、求人詳細には「この求人は0ENで作成されています」という企業向け導線を追加した。ページは既存のOS寄りUIテーマに合わせた文字中心の構成で、画像素材は使用していない。将来OGP・投稿用画像などが必要になった場合はCanva作成素材を別途管理する。
