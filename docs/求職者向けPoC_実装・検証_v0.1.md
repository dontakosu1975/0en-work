# 求職者向けPoC 実装・検証 v0.1

作成日：2026-10-07。対象：`poc/job-seeker-v0.1`。参考：`求職者向けPoC_参考実装レビュー_2026-10-07.md`。frontend-designを明示的に使用。

## 実装した範囲

トップ、求人一覧・キーワード／勤務地／仕事の種類／雇用形態検索、6件ごとのページ切り替え、求人詳細、企業指定先への外部応募導線。URLに条件とページを保持し、詳細から一覧へ戻る際にも復元する。結果ゼロ、未掲載・掲載終了、応募先未設定をそれぞれ表示する。

深緑・紙色の検索中心のトップと、給与・勤務地・雇用形態を比較しやすい縦型一覧。詳細は条件サマリーと本文。モバイルではサマリーを先頭へ移す。応募先は別小窓で確認する。

## データの接続

既存企業ポータル・取り込み・入力PoCをこのPoC内に複製。元ファイルには変更なし。4176の企業側と求職者側だけがlocalStorageを共有する。Jobの編集状態と掲載状態を分離し、公開中PublicationCycleの参照先となる完成Revisionを表示する。公開後の新しい作成中版が勝手に公開されない。終了・期限超過した掲載回は表示しない。

公開向けの投影関数は既存values/listsの項目を直接使用し、新しい正式求人スキーマは作っていない。内訳不明の給与を推定しない。明示された上限のみ表示する。HTMLはテキストとして表示する。

## 参考実装の扱い

候補リポジトリのコード流用なし。URL検索、一覧比較、本文と応募導線の分離という設計パターンを独自実装した。既存取り込みPoC由来のJSZipはそのLICENSEとともに継承。

- Node：掲載時Revisionの固定、期限終了・停止・未来の掲載、総額3表記、基本給＋手当＋固定残業代、未確定内訳、応募先必須、危険URL拒否を確認。
- ブラウザ：初期掲載8件、岡崎市検索2件、雇用形態条件の維持、ページ2の2件表示、結果ゼロ、詳細直URLと再読み込みを確認。
- 企業側で原稿0001の掲載停止→求職者側応募ボタン0件、再掲載→上部・下部2件へ復帰を確認。同一オリジンの別タブ反映を確認。
- 応募先未設定・掲載終了の求人は応募ボタン0件。確認ダイアログ表示を確認。実際の外部応募は未実行。
- 1440／768／390pxを画像確認。390pxのトップ・詳細で横はみ出しなし。最終遷移テストでJavaScript例外なし。

## 制約・次の検証

架空サンプル10件。実求人・元Excel・個人情報は同梱しない。企業マスタは従来のページ内仮状態、求人はブラウザ内保存。別端末への配信、認証、D1、実際の公開、応募情報保存、AI、法令判定エンジンはない。サンプルの完成状態はチェック合格の証明ではない。

SEOはnoindex、JobPostingは未出力。本番では公開求人と一致する構造化データ、SSR・正規URL、404/410、求人終了時処理を別途実装・検証する。

次は実案件の許可されたデータで、仕事内容・給与・試用条件・変更範囲の公開表示が意図どおりかを企業担当者と確認する。スマートフォンで条件比較と応募先確認が迷わずできるかも評価する。
