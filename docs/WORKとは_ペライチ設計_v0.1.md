# 「WORKとは？」ペライチ設計 v0.1

- 更新日：2026-10-19
- 状態：Phase 0 正式設計
- 公開URL：`/about-work/`
関連ページ：[`WORK掲載ガイドライン_v0.1.md`](WORK掲載ガイドライン_v0.1.md)

## 1. ページの目的

0ENで使う「WORK」という言葉を、初めて訪れた人に短く伝える。WORKの意味を「仕事」や完成した成果物に限定せず、同時に「何でも0ENに掲載できる」という誤解を防ぐ。

このページでは、次の3段階を分けて説明する。

1. **WORKの定義**：自分や自分たちが取り組んでいること。
2. **当事者の確認**：自分・自分たちの取り組みとして紹介しているか。
3. **掲載可否の確認**：法令・0ENのルール・公序良俗に反していないか。

## 2. ページ構成と掲載コピー

### A. ファーストビュー

小見出し：`0EN WORK GUIDE`

H1：

> WORKって、なに？

リード：

> **あなたや誰かが取り組んでいることは、WORKになり得ます。**

本文：

> 0ENでは、自分や自分たちが取り組んでいることを「WORK」と呼びます。仕事だけでなく、趣味、創作、お店、情報発信、研究、地域活動、求人なども含まれます。
>
> 完成していなくても、あなたや誰かが取り組んでいることはWORKになり得ます。

### B. WORKの例

見出し：`仕事だけではありません。`

| 取り組み | 例 |
|---|---|
| 作る | 小さなアプリを開発する、木工で家具を作る |
| 続ける | 音楽活動を続ける、地域の清掃活動をする |
| 営む | お店を運営する、新しいメニューを始める |
| 伝える | ゲームの攻略情報をまとめる、地域のお店を継続して紹介する |
| 募集する | 一緒に働く人を募集する |

結び：

> 特別な作品や完成したサービスがなくてもかまいません。

### C. 自分が当事者かを確かめる

見出し：`それは、あなた自身やあなたたちが取り組んでいることですか？`

本文：

> 初期の0ENでは、自分・自社・自分たちが主体となっているWORKを紹介します。他人のお店や作品そのものを、第三者がその主体になり代わって登録する場所ではありません。
>
> 誰かの活動を紹介する場合も、継続して取材する、検証する、情報をまとめて発信するなど、あなた自身が行っている取り組みを紹介します。

### D. WORKかどうかと掲載できるかを分ける

見出し：`WORKなら、何でも公開できる？`

本文：

> WORKに当てはまることと、0ENに掲載できることは別の確認です。公開にあたって、内容が法令・0ENの掲載ルール・公序良俗に反していないかを確認します。

3段階の図：

```text
01  WORKの定義       自分や自分たちが取り組んでいること
          ↓
02  当事者の確認     自分・自分たちの取り組みとして紹介していること
          ↓
03  掲載基準の確認   法令・0ENのルール・公序良俗に反していないこと
```

ジャンルについて：

> 商売、政治、宗教、趣味など、ジャンルだけで一律に決めるのではなく、実際の行為や掲載内容を基準に照らして判断します。

### E. ガイドラインへの案内

本文：

> 違法行為や犯罪の募集、権利侵害、詐欺、差別・嫌がらせ、露骨な性的コンテンツ、危険行為を助長する内容などは掲載できません。詳しい内容はWORK掲載ガイドラインをご確認ください。

リンク：`WORK掲載ガイドラインを見る →`（`/work-guide/`）

一般WORKの登録・紹介フローはまだ提供しないため、「自分のWORKを紹介する」など未実装の登録CTAは表示しない。

## 3. 見せ方

- 既存LPの白・チャコール・青を使い、編集記事のような読みやすいページにする。
- 求人原稿、採用管理画面、特定職種の写真をビジュアルとして流用しない。写真は必須ではない。
- 例は大量の○×比較にせず、5つの動詞と具体例で見せる。
- 「定義」「当事者」「掲載可否」は、色だけに頼らず見出しと番号で区別する。
- PCでは読みやすい幅の本文と横並びの段階表示、スマートフォンでは一列の順序表示にする。
- ガイドラインへのリンクはページ本文とフッターの両方に置く。

## 4. ページ上で避ける表現

- 「健全な活動だけがWORK」など、WORKの定義と掲載基準を混同する表現。
- 「何でも掲載できる」「ジャンルは完全自由」など、掲載判断がないように見える表現。
- 「作品」「商品」「サービス」だけに対象を絞る表現。
- 完成・販売・職業であることを必須に見せる表現。
- 第三者が他者のWORK主体になり代わって登録できるように見える表現。
- 実装されていないWORK登録、アカウント作成、問い合わせへの誘導。

## 5. Phase 0 の完了条件

- `/about-work/` にWORK解説ページが実装されている。
- `/work-guide/` のWORK掲載ガイドラインが存在し、解説ページからリンクされている。
- トップページからWORK解説ページへ移動できる。
- PCとスマートフォンで表示を確認し、見出し・本文・3段階表示に欠けや横はみ出しがない。
- WORKの定義、当事者、掲載可否が順に理解できる。
- 未実装の「WORKを紹介する」導線は表示されていない。
- リンク、キーボードフォーカス、ページタイトル、見出し構造を確認する。
