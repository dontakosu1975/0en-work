# 企業向けかんたん入力：画面ワイヤー・質問削減レビュー v0.1

設計日：2026-10-06／基準コミット：a11f267／レビュー案。画面・フォームは未実装。

## 1. 前提とレビュー結論

参照：[企業向けかんたん入力フロー_v0.1.md](企業向けかんたん入力フロー_v0.1.md)、[求人共通スキーマ_v0.2_改訂案.md](求人共通スキーマ_v0.2_改訂案.md)、[実求人適合テスト_v0.1.md](実求人適合テスト_v0.1.md)、[0EN掲載ルール設計_v0.1.md](0EN掲載ルール設計_v0.1.md)、[設計メモ_2026-10-06_追加案.md](設計メモ_2026-10-06_追加案.md)。参照資料の未確定事項は引き続き要確認。本書は法令の新解釈や競合の現行画面仕様を確定しない。

6ステップを維持し、32質問グループを21画面カードにまとめる。任意補足2カードを除く基本配置は19カード。ただし**32の意味上の確認を21に減らしたわけではない**。カード内に複数の入力・選択がある。条件質問・繰返し手当・シフト・初回企業登録は別加算する。

実際の質問削減は、確認済み情報の再入力をなくす、同一原因の確認を一度にする、回答済み条件に対する不要な子質問を隠すことで行う。給与・契約・勤務条件の不明を「なし」で埋めて件数を減らさない。通常求人を一律運営承認にしない。

## 2. 共通の画面構成

以下はテキストワイヤー。角括弧は操作候補、丸括弧は設計注記。画面番号・カード番号・Q/C番号は設計用であり企業画面に出さない。

```text
求人を作成                       [下書き保存]
仕事 → 給与 → 勤務 → 契約 → 待遇 → 確認
会社：登録済みの募集企業名        [会社情報を確認]

この画面の質問
  回答に応じて必要な内容だけ表示
  わからない項目は「後で確認」を選択

[戻る]                              [次へ]
```

「次へ」は公開操作ではなく、未回答があっても下書きとして進める案。必須条件は最終確認まで未完了として残す。保存状態と公開状態を区別する。スマートフォンでは1列、給与合計は関連入力の直下に置く。補足説明は必要時に開くが、重要な条件は補足の中へ隠さない。企業情報へのリンクは画面5の同じ情報を開き、別の正本を作らない。

## 3. 各画面のワイヤー

### 画面1：仕事と勤務地（6カード、うち任意1）

```text
どんな仕事の募集ですか？
① 仕事の名前 [                         ]
   仕事の種類 [候補を選択・変更          ]
② 雇用形態   [正社員／パート等          ]
③ お願いする仕事
   [主な作業を箇条書きでも入力できます  ]
④ [+ 応募に必要な資格・経験を追加]
   （開くと「必須」「あれば歓迎」を区別）
⑤ 働く場所 [登録済み職場を選ぶ／別の場所]
   名前・住所：選択した内容を表示 [変更]
   （訪問・現場勤務なら担当エリアを追加）
⑥ 採用後に変わる可能性はありますか？
   仕事の内容 [変わらない／変わる／後で確認]
   働く場所   [変わらない／変わる／後で確認]
   （変わる行だけ、変更の範囲を入力）
```

職種候補は企業が確定する。応募資格は任意の展開欄でも「必須資格がない」と自動判定しない。未入力時はプレビューに資格未記載を示し、職種別チェックで必要になった場合だけ確認する。勤務地は企業所在地と同じとは限らない。変更の有無2行は一括「全部なし」にしない。

### 画面2：給与（5カード）

```text
給与を教えてください
⑦ 支払い方 [月給／時給／日給等]
   基本給   [        ] 円
   [手元の原稿には総額しか書いていない]
⑧ 全員に毎回支給する手当 [なし／あり／後で確認]
   （あり：手当名・金額・支給単位 [追加]）
⑨ 固定残業代 [なし／あり／後で確認]
   （あり：金額・何時間分・対象を入力）
   → 給与総額：確認できた内訳の合計を自動表示
⑩ 上限額も表示しますか？ [表示しない／表示する]
   （表示：下限から変わる内訳と適用条件だけ入力）
⑪ 交通費・条件付き手当など [なし／あり／後で確認]
   （あり：名前・支給内容・条件を入力 [追加]）
   ※ここに入れた金額は保証給与の合計へ加えません
```

**固定残業ありの展開**：金額＋時間＋給与との単位対応、通常の時間外か深夜・休日を含むかを同じパネルで聞く。「超過分は別途全額支給」の生成表示と実際の支払い条件を同じ場所で確認する。生成文の確認を別画面でもう一度要求しない。実態が異なれば未完了を残し、文章だけ書き換えて通さない。

**総額しか分からない**：給与単位・記載総額・原稿の出典を保存し、「内訳の確認待ち」と表示。基本給に総額を代入しない。公開可能な給与として合格扱いしない。上限を表示しない選択は未知の上限を保存しないという意味であり、給与上限が存在しないという事実ではない。既存原稿の上限は申告値として保持できるが、未確認の計算値へ昇格させない。

**上限あり**：確認済み下限を参照表示し、変わる項目だけ編集。独立した手当上限を足して架空の上限を生成しない。同時に成立する内訳と根拠が必要。一律手当と実費交通費を混同しそうな場合のみ説明を展開する。

### 画面3：勤務時間と休日（3カード）

```text
いつ働く仕事ですか？
⑫ 時間の決まり方
   [毎回同じ／決まったシフト／時間帯の中で相談／その他]
   毎回同じ → 開始 [ ] 終了 [ ] 翌日 [ ] 休憩 [ ]
   シフト   → 上記の組を追加 [シフトを追加]
   相談     → [ ]～[ ] の間、1日最低 [ ] 時間
              最大時間（分かる場合） [ ]
              [+ 勤務例を追加]
⑬ 何日働き、いつ休みますか？
   勤務日数 [週／月平均] [単一／幅] [   ] 日
   休日     [曜日固定／シフト／その他] [内容を入力]
⑭ 実際の残業 [なし／あり／後で確認]
   （あり：月平均 [単一／幅] [   ] 時間）
```

日数と休日は同じカードの別質問。週の日数から休日を無断計算しない。固定週パターンの再利用も企業が実態を確認してから行う。勤務可能な時間帯、確定シフト、例には別ラベルを付け、勤務可能枠と例から所定時間を算出しない。相談型で休憩条件が評価できない場合は、長い勤務日の実働・休憩を追加確認する。

22時以降の勤務がある場合だけ「日中の勤務も募集しますか」「未成年が働ける時間帯」を確認。夜間だけの条件を求人全体の年齢制限へ変えない。固定残業代があっても実際の残業量を別に確認する。

### 画面4：契約と試用期間（2カード）

```text
契約・お試し期間について
⑮ 契約の終わりは決まっていますか？
   [決まっていない／決まっている／後で確認]
   （決まっている：期間または終了日）
   更新 [しない／自動更新／条件で判断／後で確認]
   （更新あり：判断条件・更新上限の有無と内容）
⑯ 試用期間 [なし／あり／後で確認]
   （あり：期間 [単一／幅] [ ]～[ ] [か月等]）
   （幅あり：何によって期間が決まりますか？）
   条件 [本採用と同じ／一部違う／後で確認]
   （違う項目だけ選択 → その入力欄を表示）
```

正社員でも無期を既定回答にしない。更新条件は公開原稿に必要な情報として保持する。試用時の月給→時給では給与単位と変更給与をまとめて確認し、月額手当を自動継承しない。他条件は本採用の値を参照表示して継続を確認し、再入力は要求しない。本採用条件の変更で試用条件も変わる場合は差分と確認対象を再表示する。

### 画面5：待遇と応募（4カード、うち任意1）

```text
待遇と応募先を確認してください
⑰ 会社・職場の情報（登録済み値を一覧表示）
   正式な募集企業名・所在地                 [変更]
   公開問い合わせ先                         [変更]
   加入保険（対象・条件を含む）               [変更]
   喫煙対策（この職場の内容）                 [変更]
   → 未入力・未確認の行だけ回答欄を開く
⑱ 求人全体に年齢条件はありますか？
   [なし／あり／後で確認]
   （あり：対象年齢と仕事上の理由）
   （夜間勤務の条件は画面3の回答を参照表示）
⑲ [+ 待遇の補足・職場紹介・選考説明を追加]
   手当と保険は入力済み内容を表示（再入力不要）
⑳ 応募方法 [採用する方式から選択]
   応募先 [問い合わせ先と同じ／別の受付先]
   → 選択した宛先を表示、別の場合だけ入力
```

会社・職場マスタの適用範囲と有効性を確認する。保険・喫煙対策を企業単位で全職場へ無条件流用しない。全行へのチェックボックスは置かず、最終プレビューの対象に含める案。必須値の未確認状態は一括同意では解除できない。初回企業情報確認の負担は求人作成の軽さに混ぜず別計測する。

応募方法・公開受付先の許容範囲は既存案どおり要確認。ログインメール、0ENのinfo@0en.work、転送先の個人メールを企業応募先として初期設定しない。職場の年代・定年・歓迎表現を年齢制限に変換しない。

### 画面6：原稿確認と掲載（1カード）

```text
原稿を確認してください
[仕事内容／給与／勤務／休日／待遇／試用／応募条件]
   求人原稿のプレビュー                     [該当箇所を編集]

不足している情報     ○件  [回答する]
確認が必要な情報     ○件  [内容と理由を見る]
自動で補った表示          [給与合計・定型文などを見る]

㉑ 掲載期間 [7日／14日／21日／28日]
   選択期間・公開時の終了予定を表示
   内容を確認して現在募集中の求人を公開します
[下書き保存]                         [内容を確認して掲載]
（公開条件未完了なら必要な対応を表示）
```

生成表示は元入力と結び付け、項目ごとの「確認しました」連打を要求しない。最終掲載操作が確認記録を兼ねる案。ただし固定残業の支払実態・警告への個別回答等、意味の異なる回答は保持する。28日初期値・終了時刻は要確認。期限後もJobを保持、再確認・再チェック後の再掲載は新しい掲載回とする。

「原稿をコピー」は将来の別操作候補。コピーの整形は母艦思想に沿うが、本ワイヤーで機能実装・運用開始を確定しない。公開不足とコピー可能範囲の関係は要確認。不足のある原稿を完成品として案内しない。

### 4.1 件数の再評価

| 指標 | 元案 | 本ワイヤー案 | 意味 |
|---|---|---|---|
| ステップ数 | 6 | 6 | 見通しを維持 |
| 基本質問グループ | 32 | 32を保持 | 必要な事実を削除していない |
| 配置カード数 | 32グループに対応 | 21 | 関連情報をまとめた視覚的な削減 |
| 任意補足を閉じた基本配置 | 28グループ | 19カード | 数える単位が違うため質問数削減率とは呼ばない |
| 直接入力の主なグループ | 必須・該当時7＋任意4 | 原則同じ | 空の新規求人では事実入力が必要 |
| 代表ケースの入力値 | 全11種類で14～18程度 | 原則同じ、マスタ・選択再利用で減り得る | 削減数はマスタ保有量次第、未測定 |

21カードの内訳：画面1＝6（任意1）、2＝5、3＝3、4＝2、5＝4（任意1）、6＝1。19は親カードの数であり、最大19クリックで完了するという意味ではない。給与上限カードは短い選択として残す。条件付き質問25グループは該当時に加わり、繰返し欄には固定の最大件数を置かない。

### 4.2 本当に削減できる重複と、削減してはいけない質問

- 確認済み会社・職場・宛先の再入力、待遇欄への手当・保険の再転記をなくす。
- 給与総額、日実働（確定時刻＋休憩の場合）、終了日時、超過分支給文を企業に入力させない。
- 同一原因に同じ回答で対応するチェックは1修正カードに統合し、本採用・試用の評価結果を内部では分ける。
- 固定残業の定型文を給与画面で確認した後、最終画面で同じ個別チェックを繰り返さない。ただし内容変更で確認の前提が変わった場合は再確認する。
- 上限・試用差分は変わる値だけ聞く。新たに単位が変わる部分の適用確認は削除しない。
- 月平均所定時間と根拠、給与内訳不明、契約更新、支払実態は必要な場合に残す。勤務枠・年休日から無根拠に算出して質問を消さない。

## 6. 実求人4本でのワイヤー机上レビュー

元事実・選定理由は実求人適合テストJ01～J04を参照。新しい求人事実を補完していない。以下の確認件数は元フローの見積りを引き継ぎ、カードをまとめたことだけで件数を減らさない。

| 求人 | 画面で展開する主な枝 | 残る確認 | 削減できる操作／誤入力防止 |
|---|---|---|---|
| J01 ロケーションハウス・施工管理 | ⑧一律手当、⑨固定残業、⑪条件手当、⑭残業幅、⑯同条件試用、給与根拠 | 約8グループ | 基本給260,300＋一律20,000＋固定39,700＝320,000円を自動表示。固定残業23時間と実残業20～30時間を別表示。資格手当・報奨金を合計へ加えない。上限未確認なら計算しない |
| J02 八剣伝大曽根店・ホール等 | ⑦総額のみ、⑫相談枠・3勤務例・夜間・休憩、⑯試用幅、⑰保険条件 | 約12＋方式確定後の応募受付先 | 17時～翌2時を9時間の実働としない。22時～翌3時の例と枠の不整合は確認カード。夜間だけ18歳以上を⑫で聞き、全体制限を自動設定しない。試用1～2か月の決定条件は残る |
| J03 ゆとりケア・訪問介護 | ⑤訪問エリア、⑧一律手当、⑪段階手当、⑫2シフト、⑭残業、⑯同条件試用、給与根拠・制度条件 | 約10～13 | 196,160＋17,262＝213,422円を自動表示。家賃・交通費を保証給与に足さない。契約社員から有期を推定せず、回答後のみ⑮期間・更新を展開。助成条件は一般求人へ広げない |

4本とも、必要確認を終えるまで公開可能とは結論しない。J02の3勤務例、J03の2シフト・複数手当は繰返し入力として残る。カード数に隠して負担ゼロと扱わない。給与・契約条件を知る企業が新規作成する場合と、完成MDしか持たない移行担当者の場合は別に計測する。

母艦としての確認：給与・勤務・休日・待遇・試用・応募条件をプレビューの独立見出しへ再構成し、コピー時も同じ確認済み値を使う。判定用平均時間・内部確認記録を公開原稿へ混ぜない。元原稿の魅力表現や職場紹介は任意補足で保持可能とし、構造化のために捨てない。Airワークへの完全互換・掲載保証は検証していない。

## 7. 公開前の確認カードと解決導線

| 状態 | 企業向け表示と導線 | 公開との関係 |
|---|---|---|
| error／通常の入力不足 | 「○○を入力してください」→該当欄だけ開く | 修正・再チェックまで未完了 |
| unable_to_evaluate／情報不足 | 「確認に必要な情報が足りません」→追加質問・根拠 | 回答・再評価。運営へ無条件転送しない |
| unable_to_evaluate／システム未対応 | 「この条件は現在の方法では確認できません」→採用済み代替方法があれば案内 | 代替根拠なしでは未完了。企業の同意だけで解除しない |
| warning | 疑義の箇所・理由を表示、必要な企業回答へ | 機械判定だけで一律拒否しない。記録方法は要確認 |
| 重大な安全・権利・募集主の疑義 | 疑義と追加情報・確認経路を表示 | 通常の不足と分けて保留・運営確認。解除権限は要確認 |
| block | 公開できない理由と、解消可能なら対応を表示 | 公開停止。通常の「確認しました」で解除しない |
| allow | 修正カードを出さない | 他の阻止条件がなければ企業が公開 |

同じカードで原因が異なる警告をまとめて消さない。入力内容を変更したら該当チェックを再評価し、過去の確認を新しい内容へ無条件引継ぎしない。

## 8. 優先順位・要確認・次の検証

**優先する削減**：①マスタと宛先の再入力廃止、②給与総額・定型文の手入力廃止、③試用・上限の差分入力、④関連チェックの重複確認廃止、⑤任意補足の折りたたみ。6画面をさらに減らすより、これらの重複を先に取り除く。

**面倒さが残る箇所**：平均所定時間の算定根拠、固定残業の複合対象、上限内訳の対応、試用給与単位変更、制度利用条件。給与・労務担当者の協力が必要になり得る。質問文だけで答えられるか実担当者に確認し、未対応の複雑条件を無理に通常選択へ押し込まない。

**要確認**：応募方式、資格欄を閉じた場合の職種別確認、確認済みマスタの適用・失効、最終操作でまとめられる確認の範囲、警告記録、平均時間の代替根拠、28日初期値と期限時刻、原稿コピーの不足情報表示。企業登録・本人確認は本6画面の外で設計する。初回企業の負担を省いて実サービスの簡単さを宣伝しない。

次のユーザーテストでは同じ4求人と同じ保有資料を使い、(1)再入力した事実の数、(2)判断・選択の回数、(3)追加確認の件数、(4)持ち帰った問い、(5)完了時間・誤解を計測する。目標は同じ情報の再入力ゼロ。現行Airワークとの比較は同じ条件で実測するまで未確認。「32→21だから入力が34%減った」という評価はしない。
