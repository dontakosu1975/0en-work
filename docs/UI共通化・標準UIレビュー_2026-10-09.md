# UI共通化・標準UIレビュー

対象：`poc/job-seeker-v0.2`。frontend-designを使用。評価済みv0.1、LP、スキーマ、原稿は変更なし。

## 変更

求職者トップ・一覧・詳細、企業管理、取り込み、求人入力が `assets/ui.css` を共有する。色、フォント、入力部品、基本ボタン、ダイアログ、キーボードフォーカスを集中管理。画面別CSSは配置・条件表示・固有の装飾を担当。共通CSSを最後に読み込むため、基本部品はここで調整できる。

Windows/macOSに馴染むシステムフォント、白と薄いグレー、青い選択・主要操作、控えめな角丸へ変更。OSの専用UIやウィンドウ装飾を再現するのではなく、ブラウザ上の一般的な操作部品を整える方針。

v0.2の保存キーは独立。v0.1の原稿データは変更しない。必要なら今後、明示的なデータ移行を検討する。DB、認証、掲載ロジックは変更なし。

## 検証

4画面を1440/768/390pxで確認し、横はみ出しなし。企業管理・求職者一覧のデスクトップ、求人入力給与画面・求人詳細のモバイル画像を目視確認。入力の次へ遷移、検索条件から詳細、応募先ダイアログを確認しJavaScript例外なし。Nodeの掲載・給与・応募先チェック合格。

## 起動・調整

`poc/job-seeker-v0.2` で `node server.cjs`。http://127.0.0.1:4177/ 。主な変更箇所は `assets/ui.css` の `:root` と各共通部品。画面に依存する余白・列配置は各画面のCSSで調整する。今回の見た目は評価用であり、ユーザーの使いやすさ評価はこれから。
