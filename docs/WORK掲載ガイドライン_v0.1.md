# WORK掲載ガイドライン v0.1

- 作成日：2026-10-19
- 状態：Phase 0 公開ページ案
公開URL：`/work-guide/`

> 本ガイドラインは、0ENが扱うWORKと、0ENで公開できる内容の基本方針を利用者へ伝えるための案です。利用規約や法令上の判断を代替するものではありません。公開前に0ENの利用規約・運用方針と照合します。

## 1. WORKと掲載可否は別の確認です

0ENにおけるWORKは、**自分や自分たちが取り組んでいること**です。仕事、趣味、創作、商売、情報発信、研究、政治活動、宗教活動、地域活動など、ジャンルだけでWORKかどうかを決めません。

WORKに当てはまることだけで、0ENに掲載できるとは限りません。公開する内容が法令、0ENのルール、公序良俗に反していないかを別に確認します。

## 2. 初期版で紹介できる主体

初期版では、自分・自社・自分たちが主体となって取り組んでいるWORKを紹介します。他者のWORKそのものを、第三者がその主体になり代わって登録することはできません。

他者や作品・場所を扱う場合でも、自分自身が続けている取材、検証、制作、情報整理や発信などを紹介することはできます。たとえば、ゲームの攻略情報をまとめることや、地域のお店を継続して紹介する活動は、その情報発信の取り組みとして扱えます。

## 3. 掲載できない内容

以下の内容は掲載できません。

- 法令に反する行為や犯罪を実行・勧誘・募集する内容（闇バイト等を含む）
- 著作権、商標権、プライバシーその他の権利を侵害する内容
- 詐欺、なりすまし、または重要な事実について誤認させる内容
- 他者への差別、嫌がらせ、脅迫、危害を促す内容
- 露骨な性的コンテンツ
- 人を危険にさらす行為を勧めたり助長したりする内容
- その他、法令・0ENのルール・公序良俗に反する内容

## 4. ジャンルだけで一律に判断しません

政治、宗教、商売、趣味などのジャンルだけを理由に、掲載可否を一律に決めることはしません。実際の活動や掲載内容を確認し、上記の基準に照らして判断します。

## 5. 迷ったとき

まず「自分や自分たちは何に取り組んでいるか」を具体的に説明できるか確認してください。紹介する対象の説明だけでなく、自分が行っている活動が分かるように記載してください。

このガイドラインは、WORKの種類や0ENの運用に応じて更新する場合があります。
