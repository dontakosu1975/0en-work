# WORK Hub Phase 1 PoC v0.1

固定の架空3件を使い、共通のWORK一覧から詳細へ進める最小PoCです。検索はタイトル・紹介文・主体・カテゴリなど、データ中の文字列を対象にします。

## 起動

リポジトリ直下で次を実行し、`http://127.0.0.1:4180/poc/work-hub-v0.1/` を開きます。

```powershell
python -m http.server 4180
```

`file://` から直接開くのではなく、HTTPサーバー経由で確認してください。ランタイムデータは同じディレクトリの `works.json` です。概要と未解決点は [`docs/WORK仮データ_v0.1.md`](../../docs/WORK仮データ_v0.1.md) を参照してください。

## 対象範囲

- 共通一覧、キーワード検索、WORK詳細、一覧へ戻る
- 共通表示：タイトル、summary、主体、カテゴリ、活動状態、0EN上の公開状態、更新日
- 求人固有表示：既存案の募集主名・仕事内容のみ
- `generic_work`固有表示：説明本文のみ（Phase 1の暫定スキーマ）
- DB、API、認証、編集、公開操作なし
