# Airワーク原稿 → 0EN求人変換ジェネレーター PoC v0.1

作成日：2026-10-06。貼り付けた求人プレビューを決定論的に解析し、既存入力PoCへ反映してプレビューする。AI API・ネット照会・スクレイピングは使用しない。

## 起動

`index.html`をブラウザで開く。iframeのローカルファイル制限がある環境ではNode.jsで次を実行する（インストール・外部依存不要）。

```powershell
node server.cjs
```

http://127.0.0.1:4174 を開く。停止はCtrl+C。localhostのみ待受。元の入力PoCの4173とは別。

1. Airワークのプレビュー全文を貼り付け、「変換する」。
2. 取得できた項目／選択が必要／未取得を確認。元の記載は行番号とともに参照できる。
3. 異なる候補がある場合は反映する候補を選ぶ。選ばなければ空欄。明確な項目も「反映しない」を選べる。
4. 「確認した内容を求人入力へ反映」。下の既存6画面の入力PoCで不足を補い、6画面目で原稿を確認する。
5. 再反映は入力を置換するため確認を挟む。親ページの更新で消去。ファイル・Cookie・localStorageへの保存なし。

## 解析規則

- 既知の見出しで範囲を区切る。給与の宣伝文・給与例・試用の基本給は本採用給与候補にしない。
- 円・万円・万＋千円、全角数字、空白、波ダッシュを数値照合時だけ正規化。表示本文は元の表記を保持する。
- `月給200,000円～`はmonth/min=200000/max=null/above。nullは上限記載なしであり、無限額ではない。
- 表示の給与総額は申告値として取り込む。基本給275000円等が元原稿にあっても、今回の通常給与アダプターは総額285000円を基本給に書き換えない。
- 勤務地と企業所在地を見出しの位置で区別。勤務地前の「転勤なし」等のタグを名称にしない。
- 同じ給与・社会保険・試用の繰返しは1候補に整理し、元の全出現箇所を保持。異なる候補は確認対象。
- 重複バグが修正された場合の単一記載も扱う。空白正規化後の同一内容に限る。住所表記の差異を同一住所だと推定して統合しない。
- 見出しなし・未知の形式は空欄。部分転載の誤解を避けるため全文貼付を基本とする。最大20万文字。

## 制約

対応する表示パターンに限定したPoC。全文の法令・安全性・数字の矛盾を網羅するものではない。明確＝記載箇所の抽出が明確という意味で、求人の正しさ・公開可を保証しない。

勤務の構造化、給与内訳、職種コード、保険enum、試用給与の上限・段階条件、受動喫煙対策、契約更新、応募方法の自動生成は未実装。明示的な試用「基本給」の単位と下限は抽出できるが、範囲・以上の詳細は原文を保持して企業確認へ残す。年俸・派遣等、再利用した入力PoCに選択肢がないものは本番受付を確定しない。複数求人の一括貼付は対象外。

現在の原文取り込みは既存UIへの橋渡しであり、完全なv0.2スキーマの構造化データ・DB・APIではない。曖昧な勤務を固定勤務として計算しない。問い合わせ先から応募方式を勝手に作らない。

外部CDN・外部API・解析サービスなし。D1・認証・公開処理・LP・Edge拡張に接続しない。実案件全文・個人連絡先はGitに含めず、集計した検証結果を残す。

## CSV／タブ区切りTXT

「ファイルを読み込む」→求人を1件選ぶ→「選んだ求人を変換」。今回のTXTはUTF-8・タブ区切り。引用符内の改行も読み込み可能。文字コードは自動推定せず、必要なら選択する。XLSX直接読込・一括登録は対象外。

Paste Parser / CSV Parser → 共通Normalize（候補と確認状態）→既存入力PoCアダプター、という構成。入力元固有の列コードや見出しは各Parserに閉じ込める。

271列サンプルで確認した列コードと日本語値を使用。未確認のCD値や給与表示ラベルは推定しない。固定残業・一律手当あり／不明の給与は総額か不明として確認対象。会社名の独立列はなく、勤務地名から補完しない。試用給与額を基本給と推定しない。

```powershell
node test-csv.cjs
```

実ファイル検証は `node test-csv.cjs "TXTファイルの絶対パス"`。実案件データはリポジトリに収録しない。
