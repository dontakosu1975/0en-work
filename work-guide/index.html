0EN WORK / GUIDELINES

WORK掲載
ガイドライン

WORKの意味と、0ENで公開できるかは別の確認です。

0ENでは、ジャンルだけでWORKを狭めません。一方で、公開する内容には基準があります。自分たちの取り組みか、掲載ルールに沿った内容かを確認してください。

01 / WHOSE WORK

自分や自分たちの取り組みを紹介してください。

初期版では、自分・自社・自分たちが主体となっているWORKを紹介します。他者のWORKそのものを、その主体になり代わって第三者が登録することはできません。

他者や作品・場所を扱う場合でも、自分自身が続けている取材、検証、制作、情報整理や発信などを紹介することはできます。ゲームの攻略情報をまとめることや、地域のお店を継続して紹介する活動は、その情報発信の取り組みとして扱えます。

02 / NOT ALLOWED

次の内容は掲載できません。

  • 法令に反する行為や、犯罪を実行・勧誘・募集する内容（闇バイト等を含む）
  • 著作権、商標権、プライバシーその他の権利を侵害する内容
  • 詐欺、なりすまし、または重要な事実について誤認させる内容
  • 他者への差別、嫌がらせ、脅迫、危害を促す内容
  • 露骨な性的コンテンツ
  • 人を危険にさらす行為を勧めたり助長したりする内容
  • その他、法令・0ENのルール・公序良俗に反する内容

03 / CONTENT, NOT CATEGORY

ジャンルだけで一律に判断しません。

政治、宗教、商売、趣味などのジャンルだけを理由に、掲載可否を一律に決めることはしません。実際の活動や掲載内容を確認し、上記の基準に照らして判断します。

迷ったときは「自分や自分たちは何に取り組んでいるか」を具体的に説明できるか確認してください。対象の説明だけでなく、自分が行っている活動が分かるように記載してください。
