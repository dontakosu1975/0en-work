# 求人 URL 生存チェック β版

Windows 10/11 64 bit 向けの単一ファイル版。起動すると一時ディレクトリに展開され、アプリ内のローカルサーバーを使用します。インターネット接続が必要です。元リストの書き戻し・削除は行いません。

終了・基準日・要確認等の判定は Phase 1 のローカル版を引き継ぎます。パラメータの自動修正には未対応。削除候補と要確認は人が確認してください。

ソースのローカル確認：`npm ci` の後、`npm test` と `npm start`。単一実行ファイルの作成：`npx electron-builder --win portable --x64 --publish never`。Node.js 22 以降が必要です。

β版の実行ファイルは署名されていません。Windows で初回に警告が出る可能性があります。
