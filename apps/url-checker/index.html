求人 URL 生存チェック β版

URL リストの確認を、まとめて。

バイトルの求人や採用ページの URL をチェックし、維持・削除候補・要確認に分類する Windows アプリです。求人の追加や削除は行いません。

Windows 版をダウンロード

β版 0.1.0 · Windows 10 / 11（64 bit） · 単一の実行ファイル

使い方

  1. ダウンロードした exe ファイルを起動します。
  2. LT の指定 URL を、区切りの「×」を含めて貼り付けます。
  3. 必要に応じて基準日を設定し、チェックを実行します。
  4. 判定理由を確認し、維持する URL をコピーします。

β版です。削除候補と要確認は、実際にリストを変更する前に人が確認してください。pname などのパラメータの自動修正には対応していません。

動作について

インターネット接続が必要です。チェック処理はお使いの PC で動きます。初回起動時に Windows の警告が表示される場合があります。

URL リストや判定結果を、元のリストへ自動で書き戻すことはありません。
